# Team-Software-Engineering

Introduction:\
This is a text-based puzzle solving escape room type game featuring multiple puzzles of varying difficulty based around the various topics of Computer Science, it is built in python as part of CMP2804 Team Software Engineering.

The Team:\

Louie Maloney - UI/UX Designer\
Kacper Leszczynski - Lead Developer\
Sarah Varughese - Puzzle Designer\
Brooke Hart - Documentation Manager

Overview:\
The player navigates rooms solving puzzles to gains access to other rooms until they solve the final puzzle and are able to escape. The puzzles have varying difficulty and all of them include ASCII art of the room to give the user a better idea of what each puzzle is like.
